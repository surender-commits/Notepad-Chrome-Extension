# Simple Notes Sidebar Chrome Extension

A lightweight Chrome extension that adds a simple notepad sidebar to your browser. Notes are automatically saved using local storage, allowing you to keep important text accessible across browsing sessions.

## Features

* 📝 Simple sidebar notepad
* 💾 Automatic local storage saving
* 📋 One-click Copy button
* 📥 One-click Paste button
* 🔍 Adjustable font size

  * Increase Font Size
  * Decrease Font Size
  * Reset Font Size
* 🗑️ Clear Notes button
* ⚡ Fast and lightweight
* 🔒 No external servers or data collection

## How It Works

The extension opens a notepad sidebar directly inside Chrome. Any text entered is automatically saved to local storage, so notes remain available even after closing or reopening the browser.

Quick Copy and Paste buttons make text management easier, while built-in font controls improve readability. The Clear Notes button allows you to instantly reset the notepad when needed.

## Installation

1. Download or clone this repository.

2. Open Chrome and navigate to:

   ```
   chrome://extensions/
   ```

3. Enable **Developer Mode**.

4. Click **Load unpacked**.

5. Select the extension folder.

6. The extension is now ready to use.

## Usage

1. Open the extension sidebar.
2. Start typing notes.
3. Notes are saved automatically.
4. Use:

   * **Copy** to copy notes in above section.
   * **Paste** to insert clipboard content.
   * **Increase** or **Decrease** to adjust font size.
   * **Reset** to restore the default font size.
   * **Clear Notes** to remove all content.

## Privacy

This extension stores notes locally in your browser using Chrome's local storage. No data is transmitted to external servers.
